## 1. КЛЮЧЕВЫЕ КУРЬЕРСКИЕ СИСТЕМЫ

### **InPost (Paczkomat24)**

**Структура**: Сеть автоматических шкафчиков + курьерские доставки

**Цены (действуют с 1 марта 2025)**:
- **Paczkomat 24/7** (Gabaryt A 64×38×8 см): 14,13 PLN netto (17,40 PLN brutto)
- **Paczkomat 24/7** (Gabaryt B 64×38×19 см): 16,03 PLN netto (19,68 PLN brutto)
- **Paczkomat 24/7** (Gabaryt C 64×38×41 см): 20,43 PLN netto (25,13 PLN brutto)
- **Kurier domowy**: ~18 PLN netto
- **Szybkie Zwroty**: 12,47 PLN netto

**Условия подключения для ИП**:
- Договор через Manager Paczek (https://manage.inpost.pl)
- Требуется token API ShipX (длина ~300-330 символов)
- Вес посылки: макс 25 кг
- Доступно: выбор пачкомата на карте, автоматический выбор, уведомления SMS/email

**Комиссии**: Зависят от объема (требуется уточнение напрямую с InPost)

**Особенности**:
- ✅ Наиболее популярная система в Польше (~13,000 пачкоматов)
- ✅ Синхронизация с большинством маркетплейсов
- ✅ 48 часов хранения в автомате
- ❌ Вес ограничен 25 кг

## 4. ТЕХНИЧЕСКАЯ ИНТЕГРАЦИЯ — ПОШАГОВО

### **Для InPost WooCommerce (официальный плагин)**

**Требования**:
- WordPress 5.0+
- PHP 7.4+
- Плагин Flexible Shipping (бесплатно)
- Активированный ShipX API на Manager Paczek

**Шаги интеграции**:

1. **Получить Token API ShipX**:
   - Перейти на https://manage.inpost.pl
   - Войти в аккаунт
   - Закладка "Moje Konto" → "API"
   - Скопировать token (~300-330 символов)

2. **Установить плагины**:
   - WooCommerce → Plugins → Add Plugin
   - Поиск: "Flexible Shipping"
   - Установить и активировать
   - Поиск: "WooCommerce InPost"
   - Установить и активировать

3. **Добавить credentials**:
   - WooCommerce → Settings → Shipping → InPost
   - Вставить Token ShipX
   - Нажать "Save"
   - Проверить статус (должно быть "Connected")

4. **Создать метод доставки**:
   - WooCommerce → Settings → Shipping → Add Shipping Zone
   - Выбрать зону (например, Poland)
   - Добавить метод: InPost
   - Выбрать услуги (Paczkomat, Kurier Standard, Kurier C2C)
   - Установить стоимость (или бесплатно)
   - Сохранить

5. **Тест**:
   - Перейти в корзину (frontend)
   - Проверить наличие опции "InPost"
   - Выбрать paczkomat на карте
   - Завершить заказ

**Готово!** Клиенты могут выбирать пачкоматы в корзине.

---

### **Для Furgonetka WooCommerce (самый простой)**

**Требования**: WooCommerce установлен, WordPress 5.0+

**Шаги интеграции**:

1. **Установить плагин**:
   - WooCommerce → Plugins → Add Plugin
   - Поиск: "Furgonetka"
   - Установить "Furgonetka.pl: Integracja z WooCommerce"
   - Активировать

2. **Настройка**:
   - WooCommerce → Settings → Shipping
   - Плагин автоматически появится
   - Не требуется никакая авторизация!
   - Плагин автоматически показывает курьеров и цены в real-time

3. **Для клиента**:
   - В корзине видит все курьеры с ценами
   - Выбирает подходящий
   - При оформлении платит за доставку

4. **Для вас**:
   - После оформления заказа платишь Furgonetka только за отправленные посылки
   - Без абонамента, без минимумов

**Готово!** Буквально 5 минут установки.

---

### **Для Base.com (для масштабирования)**

**Требования**: WooCommerce + REST API включен

**Шаги интеграции**:

1. **Зарегистрироваться на Base.com**:
   - https://base.com/
   - Sign Up
   - Пройти 14-дневный фрилось

2. **Сгенерировать REST API ключи в WooCommerce**:
   - WooCommerce → Settings → Advanced → REST API
   - Нажать "Create an API key"
   - Description: "Base.com"
   - Permissions: Read/Write
   - Сгенерировать
   - Скопировать Consumer Key и Consumer Secret

3. **Добавить WooCommerce в Base.com**:
   - Base.com → Integracje
   - "+Dodaj nową"
   - Выбрать "WooCommerce"
   - Вставить Consumer Key и Consumer Secret
   - Store URL: https://yoursite.com
   - Сохранить

4. **Добавить курьеров в Base.com**:
   - Base.com → Integracje
   - "+Dodaj nową"
   - Выбрать "InPost" (или DPD, GLS)
   - Следовать инструкциям (может потребоваться token)
   - Сохранить

5. **Начать работу**:
   - Заказы синхронизируются автоматически
   - Base.com → Zamówienia (все заказы со всех каналов)
   - Выбрать заказ → сгенерировать этикетку
   - Доставить через выбранного курьера

**Готово!** Один интерфейс для управления всем.

## 5. УСЛОВИЯ ПОДКЛЮЧЕНИЯ ДЛЯ ИП (JDG)

### Общие требования для ИП

**1. Регистрация в CEIDG**:
- ИП должен быть зарегистрирован как JDG (самостоятельно через https://biznes.gov.pl/)
- Получить NIP (можно через CEIDG сразу)
- Время: ~10-15 минут онлайн

**2. E-Doręczenia (обязательно с 1 января 2025)**:
- Все ИП в CEIDG ОБЯЗАНЫ подать заявку на электронный адрес доставки
- Это цифровой адрес для получения уведомлений от органов власти
- Подается через https://www.biznes.gov.pl/
- Путь: "Skrzynki do e-Doręczeń" → "Złoż wniosek"
- Процесс: выбрать "Utworzenie adresu u publicznego dostawcy" → CEIDG → подписать Profil Zaufany → отправить
- Обработка: обычно ~5 рабочих дней

**3. Документы для курьеров**:
- Паспорт/ID (фото + копия)
- Адрес проживания
- Адрес деятельности ИП
- Банковский счет (для расчетов)
- Свидетельство из CEIDG (опционально)

**4. Договоры** (курьер-зависимые):

| Курьер | Как подключиться | Что нужно |
|--------|-------------------|----------|
| **InPost** | Manager Paczek или интеграторы | NIP + адрес + паспорт |
| **DPD** | https://www.dpd.com/pl/pl/oferta-dla-firm/ | NIP + адрес + банк счет |
| **GLS** | https://www.gls-group.com/PL/pl/ | NIP + адрес + контакты |
| **ORLEN** | Через агрегаторы (Sendit, ShipCenter) | Регистрация на агрегаторе |
| **Furgonetka** | Просто установить плагин | Ничего! |

## 8. РЕКОМЕНДАЦИИ ПО ВЫБОРУ

### **ВАРИАНТ 1: Минимум затрат (ДО 50 посылок/месяц)** ⭐ ЛУЧШИЙ ДЛЯ НОВИЧКА

**Рекомендация**: **Furgonetka.pl + MultiParcels**

**Как работает**:
- Furgonetka: бесплатный плагин + платишь за каждую отправленную посылку
- MultiParcels: бесплатный выбор курьеров в checkout
- Клиент видит цены всех курьеров в реальном времени, выбирает дешевый вариант

**Стоимость**:
- Установка: бесплатно
- Абонамент: 0 PLN/месяц
- Платеж: только за отправленные посылки (~12-28 PLN за посылку в зависимости от курьера)

**Экономия**: 30-50% vs стандартные договоры

**Линки**:
- Furgonetka: https://wordpress.org/plugins/furgonetka/
- MultiParcels: https://ru.wordpress.org/plugins/multiparcels-shipping-for-woocommerce/

**Когда выбрать**: Если вы новичок, не знаете объемы, не хотите платить абонаменты.

### ✅ ЛУЧШИЙ ВЫБОР ДЛЯ НОВИЧКА

1. **Установить Furgonetka** (бесплатно, 5 минут)

2. **Месяц 3-4**: Base.com (пробный период, проверка функционала)
3. **Месяц 5+**: Base.com + договоры с 1-2 основными курьерами

### ⚠️ КРИТИЧЕСКИЕ МОМЕНТЫ

- ❌ Не подписывайте долгосрочные договоры с курьерами на старте
- ❌ Не платите абонаменты, если объем <40 посылок/месяц
- ✅ Начните с Furgonetka (нет рисков)
- ✅ Создайте e-Doręczenia адрес (обязательно по закону)
