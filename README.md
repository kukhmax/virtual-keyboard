## 1. ОБЗОР РЕШЕНИЯ

### Как будет работать для вашего магазина текстиля:

**ДО установки Furgonetka**:
```
Покупатель добавляет товар → 
Идет в корзину → 
Видит ДА/НЕТ только один вариант доставки (или никакого) → 
Платит → 
Заказ создан
```

**ПОСЛЕ установки Furgonetka**:
```
Покупатель добавляет товар → 
Идет в корзину → 
🎯 ВИДИТ ВСЕ ДОСТУПНЫЕ КУРЬЕРЫ С ЦЕНАМИ (InPost, DPD, GLS, ORLEN и др) → 
Выбирает подходящий → 
Видит финальную цену (товар + выбранная доставка) → 
Платит → 
Заказ создан
```

### Главные преимущества для вашего магазина текстиля:

| Преимущество | Что это означает |
|---|---|
| **Клиент выбирает курьера** | Они видят цены, выбирают дешевый вариант, вам выгодно |
| **Бесплатный плагин** | Ноль расходов на установку |
| **Без абонамента** | Платите только за отправленные посылки |
| **До 70% дешевле** | Furgonetka торгует со скидками у курьеров |
| **Синхронизация статусов** | Клиент видит отслеживание посылки в автоматическом режиме |
| **Управление возвратами** | "Furgonetka Zwrot" - управление вернувшимися товарами |

## ШАГ 1: ПОДГОТОВКА ВАШЕГО МАГАЗИНА

### 1.1 Проверяем, что WooCommerce работает

1. **Войдите в админ-панель** WordPress:
   - https://yoursite.com/wp-admin
   - Введите логин и пароль

2. **Слева найдите меню "WooCommerce"**:
   ```
   WordPress меню (слева) → WooCommerce
   ```

3. **Если его нет** - нужно установить WooCommerce:
   - Plugins → Add New
   - Поиск: "WooCommerce"
   - Кнопка "Install Now"
   - Кнопка "Activate"
   - Ждем 2-3 минуты

### 1.2 Настраиваем основные параметры WooCommerce

1. **WooCommerce → Settings**:
   - Слева кликните на "Settings"

2. **Вкладка "General"**:
   - Магазин находится где? **"Poland"**
   - Валюта: **"Polish Złoty (PLN)"**
   - Сохраните: **"Save changes"**

3. **Вкладка "Products"**:
   - Убедитесь, что установлены размеры товаров
   - Для текстиля это важно для расчета доставки

4. **Вкладка "Shipping"** (ВАЖНО):
   - Должны быть созданы зоны доставки
   - Если их нет - создаем (см. ШАГ 3)

### 1.3 Добавляем размеры и вес вашим товарам

Это нужно для точного расчета доставки!

**Для каждого товара**:

1. **WooCommerce → Products** → выберите товар (например, рубашка)

2. **В редакторе товара внизу** найдите секцию:
   ```
   Shipping (или Физические параметры)
   ```

3. **Заполните**:
   - **Weight (вес)**: например, `0.2` кг (рубашка легкая)
   - **Dimensions (размеры)**: 
     - Length (длина): `30` см
     - Width (ширина): `25` см
     - Height (высота): `5` см

4. **Сохраните товар**: "Update"

**Примеры весов для текстиля**:
- Футболка: 0.15-0.2 кг
- Рубашка: 0.2-0.3 кг
- Брюки: 0.3-0.4 кг
- Платье: 0.2-0.4 кг
- Куртка: 0.8-1.2 кг

⚠️ **ВАЖНО**: Вес должен быть реалистичным! От этого зависит расчет доставки.

## ШАГ 2: УСТАНОВКА ПЛАГИНА FURGONETKA

### 2.1 Установка плагина

1. **WordPress админ-панель** → **Plugins** (слева)

2. **Кликните "Add New"**:
   ```
   Plugins → Add New
   ```

3. **В поле поиска** введите:
   ```
   Furgonetka
   ```

4. **Найдите плагин** "Furgonetka.pl: Integracja z WooCommerce":
   - Автор: EASYPACK Sp. z o.o.
   - Описание: "Integracja sklepu WooCommerce..."

5. **Кликните "Install Now"**:
   ```
   Install Now → Activate
   ```

6. **Ждем активации** (~10 секунд)

7. **После активации** вы увидите сообщение:
   ```
   ✅ Plugin activated successfully
   ```

### 2.2 Проверяем установку

1. **WooCommerce → Settings**

2. **Вкладка "Shipping"**

3. **Должны увидеть новую опцию**:
   ```
   Furgonetka
   ```

4. Если видите - ✅ плагин установлен правильно

## ШАГ 3: НАСТРОЙКА ДОСТАВКИ В WOOCOMMERCE

### 3.1 Создаем зону доставки "Польша"

1. **WooCommerce → Settings → Shipping**

2. **Кликните "Add Shipping Zone"**:
   ```
   Add Shipping Zone (большая кнопка справа)
   ```

3. **Заполните форму**:

   **Zone name (название зоны)**:
   ```
   Poland (или "Polska")
   ```

   **Zone regions (регионы в зоне)**:
   - Нажмите "Select countries"
   - Выберите: **Poland**
   - Нажмите "Add countries"

4. **В секции "Shipping Methods"** нажмите:
   ```
   Add Shipping Method (кнопка)
   ```

5. **Выберите из списка**:
   ```
   Furgonetka
   ```

6. **Кликните "Add"**

7. **Появится форма Furgonetka**:
   
   | Поле | Что вводить |
   |------|------------|
   | **Method Title** | "Furgonetka" (или "Выберите курьера") |
   | **Cost** | Оставьте пусто или "0" (цена считается от курьеров) |
   | **Tax status** | "Taxable" или "Non-taxable" (зависит от вашей налоговой политики) |

8. **Сохраните**:
   ```
   Save changes (внизу страницы)
   ```

### 3.2 Проверяем, что зона создана

На странице **WooCommerce → Settings → Shipping** вы должны видеть:

```
✅ Poland (1 method)
   └─ Furgonetka ✏️ ❌
```

Если видите - отлично! Переходим дальше.

## ШАГ 4: ТЕСТИРОВАНИЕ КАК ВИДИТ КЛИЕНТ

### 4.1 Открываем магазин от лица покупателя

1. **Откройте ваш магазин** в новой вкладке браузера:
   ```
   https://yoursite.com
   ```

2. **Добавьте товар в корзину**:
   - Кликните на любой товар (например, рубашку)
   - Нажмите "Add to cart"

3. **Откройте корзину**:
   - Значок корзины вверху сайта ИЛИ
   - Нажмите "Cart" в меню

### 4.2 Проверяем, появилась ли доставка

**На странице корзины**:

Прокрутите вниз и найдите секцию:
```
Shipping (Доставка)
```

Там должны быть опции курьеров:
```
☐ Furgonetka – от 12,99 PLN
☐ Furgonetka – от 17,40 PLN (InPost)
☐ Furgonetka – от 20,00 PLN (GLS)
... и другие
```

⚠️ **Если не видите**:
- Убедитесь, что в профиле установлена страна **Poland**
- Проверьте вес товара (может быть 0)
- Обновите страницу (Ctrl+F5)

### 4.3 Тестируем выбор курьера

1. **Выберите один из предложенных курьеров**:
   ```
   ☑ Furgonetka – 12,99 PLN (ORLEN)
   ```

2. **Цена должна добавиться** к общей сумме:
   
   **Было**:
   ```
   Subtotal: 50,00 PLN
   Shipping: -
   Total: 50,00 PLN
   ```

   **Стало** (после выбора Furgonetka):
   ```
   Subtotal: 50,00 PLN
   Shipping: 12,99 PLN
   Total: 62,99 PLN
   ```

3. **Выберите другого курьера**, цена должна измениться:
   ```
   ☑ Furgonetka – 17,40 PLN (InPost)
   ```

   **Итого станет**:
   ```
   Total: 67,40 PLN
   ```

✅ **Если все работает** - отлично! Furgonetka интегрирована правильно.

## ШАГ 5: ПЕРВЫЙ РЕАЛЬНЫЙ ЗАКАЗ

### 5.1 Оформляем заказ как клиент

1. **На странице корзины**:
   - Выберите любого курьера (например, ORLEN за 12,99 PLN)

2. **Нажмите "Proceed to checkout"**:
   ```
   Proceed to checkout (кнопка внизу)
   ```

3. **На странице checkout**:
   - Заполните данные покупателя:
     ```
     First Name: Jan
     Last Name: Nowak
     Email: jan@example.com
     Phone: +48123456789
     Address: Marszałkowska 1
     City: Warszawa
     Postcode: 00-021
     Country: Poland
     ```

4. **Проверьте доставку**:
   - В секции "Shipping" должен быть выбран ваш курьер
   - Цена рядом

5. **Нажмите "Place Order"**:
   ```
   Place Order (финальная кнопка)
   ```

### 5.2 Проверяем заказ в админ-панели

1. **WooCommerce → Orders**

2. **Найдите свой новый заказ** (вверху списка)

3. **Откройте заказ** (кликните на номер)

4. **Вы должны увидеть**:
   ```
   Order #1234
   
   Customer: Jan Nowak (jan@example.com)
   
   Items:
   - Рубашка красная x1 → 50,00 PLN
   
   Shipping: Furgonetka (ORLEN) → 12,99 PLN
   
   Total: 62,99 PLN
   
   ✅ Status: Processing (или Pending payment)
   ```

✅ **Если всё видно** - отлично! Заказ создан правильно.

## ШАГ 6: УПРАВЛЕНИЕ ДОСТАВКОЙ ПОСЛЕ ОФОРМЛЕНИЯ ЗАКАЗА

### 6.1 Создание этикетки и отправка посылки

**После того как заказ готов к отправке**:

1. **WooCommerce → Orders**

2. **Откройте заказ**:
   ```
   Order #1234
   ```

3. **Прокрутите вниз** до секции:
   ```
   Furgonetka Shipments (или Shipment)
   ```

4. **Нажмите кнопку**:
   ```
   Create Shipment (или "Utwórz przesyłkę")
   ```

5. **Появится форма**:
   
   | Поле | Что вводить |
   |------|------------|
   | **Courier** | Должен быть уже выбран (ORLEN, InPost и т.д.) |
   | **Parcel size** | Авто-определится из размеров товара |
   | **Weight** | Авто-определится из веса товара |
   | **Reference** | Оставьте пусто (авто-генерируется) |

6. **Нажмите "Create"**:
   ```
   Create Shipment (кнопка)
   ```

7. **Система создаст этикетку**:
   ```
   ✅ Shipment created successfully
   
   Tracking number: XXXXXXXXXXXX
   Courier: ORLEN
   Status: Awaiting
   ```

### 6.2 Печатаем этикетку

1. **В секции Furgonetka** нажмите:
   ```
   Download Label (или "Pobierz etykietę")
   ```

2. **Скачается PDF файл** с этикеткой:
   ```
   furgonetka_label_XXXXX.pdf
   ```

3. **Распечатайте** этикетку (A4 формат)

4. **Наклейте на посылку**

### 6.3 Сдаем посылку курьеру

**Для ORLEN**:
- Сдайте на любой АЗС Orlen
- Или в партнерском пункте выдачи
- Покажите этикетку и номер отслеживания

**Для InPost**:
- Поместите в пачкомат (автомат)
- Или сдайте в InPost point

**Для DPD/GLS**:
- Курьер заберет от вас по заранее согласованному времени
- Или сдайте в их пункте

### 6.4 Отслеживание

1. **В админ-панели заказа** статус автоматически обновится:
   ```
   ✅ Shipment #XXXXX
   Status: In transit
   Tracking: https://tracking.furgonetka.pl/XXXXX
   ```

2. **Клиент видит** в его личном кабинете:
   - Email с номером отслеживания
   - Ссылка для отслеживания посылки

3. **В админ-панели WooCommerce** статус заказа:
   ```
   Order Status: Completed (когда посылка доставлена)
   ```

## РАСЧЕТ СТОИМОСТИ ДЛЯ ВАС

### Сценарий: Магазин текстиля, 50 посылок в месяц

#### Вариант 1: Используете только Furgonetka (БЕЗ договоров с курьерами)

**Стоимость в месяц**:

| Параметр | Расчет | Стоимость |
|----------|--------|----------|
| **Установка плагина** | Один раз | 0 PLN |
| **Абонамент Furgonetka** | 0 (платишь только за посылки) | 0 PLN/месяц |
| **Средняя посылка** | ORLEN (12,99 PLN) | 12,99 PLN/посылка |
| **50 посылок × 12,99 PLN** | 50 × 12,99 | 649,50 PLN/месяц |
| **ИТОГО** | | **649,50 PLN/месяц** |

**Примечание**: При 50 посылках в месяц Furgonetka может **предложить вам скидку 10-30%**, нужно связаться с их поддержкой.

#### Вариант 2: Вы подключаетесь к договору с InPost напрямую

**Стоимость в месяц**:

| Параметр | Расчет | Стоимость |
|----------|--------|----------|
| **Установка плагина** | Один раз | 0 PLN |
| **Договор с InPost** | Starter пакет | 0 PLN (без абонамента) |
| **Цена за посылку (Gabaryt A)** | InPost | 17,40 PLN/посылка |
| **50 посылок × 17,40 PLN** | 50 × 17,40 | 870 PLN/месяц |
| **ИТОГО** | | **870 PLN/месяц** |

**Сравнение**:
```
Furgonetka: 649,50 PLN ✅ ЭКОНОМИЯ 220,50 PLN (25% дешевле!)
InPost:     870,00 PLN
```

#### Вариант 3: Смешанный (Furgonetka + при росте договор с популярным курьером)

**Месяцы 1-3** (Furgonetka):
```
50 посылок × 12,99 PLN (ORLEN) = 649,50 PLN/месяц
Итого 3 месяца: 1,948.50 PLN
```

**Месяцы 4+** (договор с InPost, т.к. видно популярность):
```
50 посылок × 17,40 PLN (InPost) = 870 PLN/месяц
Но если объем > 100 посылок → получаете скидку до 30%
100 посылок × 12,18 PLN = 1,218 PLN/месяц
```

### Факторы, влияющие на стоимость доставки:

| Фактор | Как влияет |
|--------|----------|
| **Вес посылки** | Тяжелее → дороже |
| **Размер** | Больше → дороже |
| **Тип доставки** | Точка-точка < Дом-точка < Дом-дом |
| **Зона доставки** | Варшава дешевле, чем отдаленные регионы |
| **Объем в месяц** | 50+ → скидка, 100+ → еще больше |

### Расчет для ВАШЕГО текстиля:

**Пример посылки**:
- Содержимое: 1 рубашка
- Вес: 0.3 кг
- Размер: 30×25×5 см (упакована)
- Тип: Точка-точка

**Цены разных курьеров для этой посылки**:

| Курьер | Цена | Примечание |
|--------|------|-----------|
| **ORLEN** | 11,97 PLN | ✅ Самая дешевая |
| **InPost** | 17,40 PLN | Популярна |
| **GLS** | ~20 PLN | Конкурентная |
| **DPD** | ~25 PLN | Дороже для мелких |

**Итог**: При 50 посылках текстиля в месяц через Furgonetka:
```
Минимум: 50 × 11,97 = 598,50 PLN (если все через ORLEN)
Максимум: 50 × 20 = 1,000 PLN (если все через GLS)
Средняя: 50 × 15 = 750 PLN/месяц (микс разных курьеров)
```

**Клиент будет выбирать дешевый вариант** → вы платите меньше чем если бы были договоры!

## ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ

### Добавляем маржу на доставку (если нужно)

**Вы можете добавить небольшую маржу** к цене доставки для прибыли:

1. **WooCommerce → Settings → Shipping**

2. **В зоне Poland** рядом с Furgonetka нажмите **Edit**

3. **В поле "Cost"** добавьте:
   ```
   [qty] - это добавит маржу к каждой посылке
   Например: [qty] + 1 = добавит 1 PLN к каждой доставке
   ```

4. **Или используйте процент**:
   ```
   [qty] * 1.1 = добавит 10% к цене доставки
   ```

**Примеры**:
```
Была доставка: 12,99 PLN
+ маржа 1 PLN: 13,99 PLN (вы получаете +1 PLN)
+ маржа 10%: 14,29 PLN (вы получаете +1,30 PLN)
```

### Добавляем несколько зон (например, EU)

Если вы будете отправлять и в соседние страны:

1. **WooCommerce → Settings → Shipping**

2. **"Add Shipping Zone"** еще раз

3. **Zone name**: "Europe"

4. **Select countries**: Чехия, Германия, etc.

5. **Add method**: Furgonetka (или другой, поддерживающий EU)

## РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: Не видны курьеры в корзине

**Причина 1**: Вес товара = 0
```
Решение: WooCommerce → Products → отредактируйте товар → добавьте вес
```

**Причина 2**: Не выбрана страна Poland
```
Решение: На checkout странице выберите страну Poland
```

**Причина 3**: Плагин не активирован
```
Решение: Plugins → найдите Furgonetka → кликните "Activate"
```

**Причина 4**: Shipping zone не создана
```
Решение: WooCommerce → Settings → Shipping → Create zone "Poland"
```

### Проблема 2: Курьеры показываются, но цены неправильные

**Решение**: Очистите кеш
```
Если у вас установлен плагин кеша (W3 Total Cache, WP Super Cache):
Plugins → найдите плагин кеша → "Clear cache"
```

### Проблема 3: После создания этикетки "Ошибка соединения"

**Решение**: Убедитесь что:
1. WordPress может обращаться к интернету (спросите у хостера)
2. API Furgonetka доступен (редко, но может быть)
3. Обновите плагин: Plugins → Furgonetka → "Update" (если есть)

### Проблема 4: Клиент не видит номер отслеживания

**Это нормально если**:
- Заказ еще не отправлен (статус "Processing")
- Этикетка еще не создана

**Когда появится**:

Была: ORLEN 11,97 PLN

Cost formula: [qty] * 1.10

Была: ORLEN 11,97 PLN

Ваша маржа: 1,20 PLN за каждую посылку

## ❌ ТИПИЧНЫЕ ОШИБКИ И КАК ИЗБЕЖАТЬ

| Ошибка | Что будет | Как избежать |
|--------|----------|-------------|
| **Вес товара = 0** | Доставка не рассчитается | Установить реалистичный вес в каждом товаре |
| **Страна не Poland** | Курьеры не появятся | На checkout выбрать Poland |
| **Нет shipping zone** | Все заказы без доставки | Создать зону Poland в Settings → Shipping |
| **Маржа слишком большая** | Клиенты уходят конкурентам | Маржа макс 10-15% от цены доставки |
| **Забыли про e-Doręczenia** | Штрафы при проверке налоговой | ОБЯЗАТЕЛЬНО создать адрес в biznes.gov.pl |
| **Не обновляют товары** | Клиенты жалуются на вес/размер | Проверять реальные параметры при каждой закупке |
